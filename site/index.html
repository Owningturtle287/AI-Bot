    Dataset formats

    Put UTF-8 text files in an unencrypted ZIP. For chat, use JSONL with one complete prompt and answer per line.

    {"prompt":"What is slope?","response":"Slope is rise divided by run."}

    JSONL also accepts instruction/output and user/assistant messages. TXT and Markdown train on passages and can be searched for excerpts.

    For large collections, add several independently trainable ZIPs. The queue saves progress on this device as it goes.
